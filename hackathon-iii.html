Explain this to anyone on the team

The website is a tiny shop with two questions. First it asks which product. Then it asks which store. You do not type. You say a number word: zero, one, two, three, four, or five. The computer only cares which of those six words you said. It is not listening for “laptop” or “Amazon”.

A function named get_features already turns 1 second of sound into a list of 900 numbers (MFCC — the same idea as lab U3W14_52). You must not change that function. Your job is to train a small CNN that looks at those 900 numbers and outputs a digit 0–5. Same idea as Fashion-MNIST guessing “shirt vs shoe”, except here the input is a sound fingerprint, not a picture.

You train in Google Colab on clean studio recordings. Then you copy the same network onto the lab server. Graders record four correct product picks in a row, then four store picks. Later you add your own voices and train again so the mic in the room still works.

One rule everyone must remember Do not change get_features (8 kHz, 30 MFCC, 15 frames). If Colab and the server use different settings, training looks great and the live mic fails.

How to fill each Colab blank

Blank in starter In simple words Look like
load_data(folder) Loop wav files. Label = number before the first _. Skip names starting with noise. Stack get_features output glob + split('_')[0]. Example: 0_b2_35.wav → label 0
train_test_split Keep ~80% to learn, 20% to test. Use stratify so every digit is in both Same sklearn call as other labs
DataLoader Serve small batches so training is not one giant tensor MH2: TensorDataset then DataLoader (shuffle=True on train)
Net extra convs Keep the given 900→400 layer. Add at least two more Conv1d + BN + ReLU. Flatten. Linear to 6. LogSoftmax H3 cell already has conv1. Fashion-MNIST shows stacking; use Conv1d not Conv2d
criterion / optimizer LogSoftmax wants NLLLoss. Adam with a small learning rate (try 0.001) U3W14_53: criterion + optimizer then the epoch loop
Train / test cells Each batch: zero_grad, forward, loss, backward, step. Count how often torch.max matches the label U3W14_53 epoch loop (they used unsqueeze(0) per sample; you can do that per batch instead)
Save Save the weights dictionary, not a mystery pickle torch.save({'net_dict': model.state_dict()}, 'speech_model.t7') — matches Order.py
