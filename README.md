# ML Visual Lab

Interactive visual explanations of classical ML and deep learning concepts.

**Live site:** https://akshay-anand010.github.io/ml-visual-lab/

## Features

- **Guided path** with local progress and a shared 2D playground across logistic / k-NN / trees  
- **Step, scrub, inspect** on regression and backprop  
- **Failure modes** — dead ReLUs, overfit trees, bad learning rates on the loss landscape  
- **New labs** — loss landscape, k-NN, softmax  
- **Notes** tagged by concept, linked to GitHub PDFs  

## Chapters

1. Classical ML — linreg, logreg, k-NN, trees, PCA, softmax, landscape  
2. Deep learning — neural nets, backprop, CNN, RNN  
3. Language — TF-IDF, Word2Vec, attention  
4. Evolution map + reference notes
